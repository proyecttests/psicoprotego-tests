# Template: Privacy

## Función
Bloque fijo de privacidad, idéntico entre tests (coherencia de
marca) salvo ajustes mínimos.

## Contenido fijo (el LLM no debe reescribir libremente)

```json
{
  "heading": "Privacidad",
  "body": "Tus respuestas no salen de tu dispositivo. No se envían a ningún servidor de Psicoprotego. Decides tú qué compartir y con quién — puedes descargar un PDF del resultado y enviarlo a tu terapeuta, o simplemente cerrar la pestaña y no quedará registro."
}
```

El LLM PUEDE reformular ligeramente para evitar copia literal entre
tests, pero sin cambiar el fondo ni añadir condiciones. Es un
bloque de confianza consistente.
